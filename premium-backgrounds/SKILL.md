# Objective
Create a clean, visual and professional presentation from the images provided.

# Steps
1. Ask for the topic, the audience and the number of slides (default: 8).
2. Analyze each image: dominant colors, empty zones for text, and tone (calm, tech, luxury...).
3. Define a 3-color palette and 1 typeface, based on the images.
4. Structure: cover, problem, solution, 3 to 4 content slides, summary, contact.
5. Use one image per slide, full screen, with short text (max 12 words per title, 3 bullets).
6. Ensure readable contrast: if the background is dark, use light text (and vice versa).
7. Deliver as .pptx, with the result in 16:9.

# Rules
- Never fill a slide with text.
- Keep the same style on every slide.
- Each image is used only once, unless the user asks otherwise.
