# Premium Backgrounds

A pack of 6 royalty-free premium background images, generated with AI and ready to use in slides, thumbnails, social posts, covers and video overlays.

## Specifications

- **Size:** 3840 x 2160 px (4K, 16:9)
- **DPI:** 300
- **Format:** JPG (quality 95)
- **Generation tool:** Black Forest API — FLUX (via the Mistral image_generation tool), processed and upscaled to 4K at 300 DPI
- **Price:** free to use

## Contents

Each folder contains:

| File | Description |
|---|---|
| `background.jpg` | The final image (3840 x 2160, 300 DPI, 16:9) |
| `prompt.txt` | The exact English prompt used to generate the image |
| `tool.txt` | The name of the generation tool used |

| Folder | Theme |
|---|---|

| [02-minimal-workspace](02-minimal-workspace/) | Minimalist desk, top-down view, neutral beige tones |

| [04-nature-and-calm](04-nature-and-calm/) | Misty mountain landscape at sunrise, pastel tones |

## Bonus: Slide skill

[SKILL.md](SKILL.md) is a reusable agent skill ("slides-with-images"). Give it to any AI coding agent to generate elegant full-screen presentations from a set of images: it analyzes the images, defines a color palette and typeface, and builds a clean 16:9 .pptx deck.

## How to use

1. Download the folder of the background you like (or the whole pack).
2. Drop `background.jpg` behind your content — every image has empty space reserved for text.
3. To recreate or adapt an image, reuse the text in `prompt.txt` with your favorite AI image tool.
